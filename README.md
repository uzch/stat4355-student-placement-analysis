# STAT 4355 — Student Placement Salary Analysis

A collaborative Applied Linear Models project for **STAT 4355** focused on modeling **salary among placed students** using the **Global Student Placement & Salary Dataset** in **R / RStudio**.

## Overview

This project investigates which student-related factors are most strongly associated with salary after placement. Our analysis centers on **placed students only**, allowing us to study differences in salary level rather than mixing salary prediction with placement prediction.

The project follows a standard applied linear modeling workflow:
- data preparation
- exploratory data analysis
- full model fitting
- residual analysis
- transformation checks
- variable selection
- influential analysis
- final model interpretation
- presentation and report development

## Analysis Goal

Our primary goal is to determine which academic, experiential, and background variables best model salary obtained after placement. We use multiple linear regression and related diagnostics to build, evaluate, and refine candidate models.
